Experiment 1: Student Grades Case Study in SIAKAD – FOR Loop

Description
This project is a simple Java program designed to evaluate the scores of 10 students. It determines whether each student passes or fails based on their score.

Features
Input scores for 10 students.
Validate scores within the range of 0 to 100.
Determine whether each student passes or fails.
Identify the highest and lowest scores among students.

Requirements
Java Development Kit (JDK)
Visual Studio Code (optional)

How to Run
Open the project in Visual Studio Code.
Make sure Java is installed.
Run the SiakadFor12.java file.
Enter the score for each student when prompted.
View the pass/fail results and the highest and lowest scores.

Evaluation Criteria
Passed: Score is 60 or higher.
Failed: Score is below 60.
Valid Score: Score must be between 0 and 100.

Technologies Used
Java
Scanner for user input
for loop for repeated score entry
if-else statements for score validation and evaluation
